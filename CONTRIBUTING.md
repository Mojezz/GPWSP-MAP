# Contributing

Thank you for helping. Please read [SECURITY.md](SECURITY.md) first. Its rules come before everything else.

## Ways to help in Phase 1

- **Translate** the site. See "How to add a language" in [README.md](README.md). You only
  need to edit one text file.
- **Improve the design** for small phones and slow connections.
- **Report problems** by opening an issue. Never include personal or real worker data in an issue.

## Ground rules for code

- Keep it simple: plain HTML, CSS and JavaScript, with no build tools.
- Put every visible word in `locales/en.json`, never directly in the HTML or JavaScript.
- Load nothing from other websites.
- Test on a small phone screen (about 360 pixels wide) before proposing a change.
